Usage

POST to https://usetaskmonster.app/api/events/ with header Authorization: Bearer <your key> and a JSON body:

{
  "title": "Client Appointment",
  "due_at": "2026-09-15T10:00:00",
  "emoji": "📅",
  "requires_rsvp": false,
  "guest_emails": ["client@example.com"]
}

Only title and due_at are required - everything else has a sensible default, including which Realm/Bucket it lands in. Add your own external_id (e.g. an order number) so you can update it later without storing TaskMonster's own event id anywhere.

Updating an event

PATCH the same URL with event_id or external_id, plus whichever fields changed:

{
  "external_id": "ORDER-1234",
  "due_at": "2026-09-16T09:00:00",
  "notify": false
}

notify defaults to true - every guest gets an updated email (this doubles as a plain "resend the invite" if you PATCH with no other fields changed). Set it to false to update silently, with no email sent.
